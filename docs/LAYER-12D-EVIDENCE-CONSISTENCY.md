# Layer 12D — Evidence independence and consistency gate

Layer 12D analyzes supplied Layer 12A facts and optional Layer 12B/12C overlays only. FACT nodes are their own roots; derived nodes inherit leaf FACT roots; missing data has neutral, empty lineage. Cycles and unresolved references are rejected.

The deterministic output uses categorical pairwise classifications, shared-root evidence families, descriptive source-layer mechanism families, contradiction groups, and static/temporal/mixed membership. It has no scores, weights, outcomes, interpretation, or prediction.
