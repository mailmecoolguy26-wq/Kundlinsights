## Authority boundary

## Reference method

The external C harness sampled the Sun chronologically over the approved annual windows, required one negative-to-nonnegative circular residual crossing, then bisected integer UTC milliseconds to a one-millisecond bracket. It generated forward and backward returns independently from the original natal Lahiri Sun target. MD coordinates used approved linear UTC-time interpolation between C-generated returns; AD and PD used cumulative integer-millisecond nominal-weight partitions.
