# Profile Career unlock foundation

`career_profile_unlock` is a future permanent `BIRTH_PROFILE` entitlement: one verified payment is assigned to one birth profile. Store purchases may be repeat-purchasable, while server access remains permanent.

Live Career reading generation and entitlement status are profile-scoped. The legacy user-wide subscription resolver remains only in the Apple/Google `career_premium_annual` payment verification and restore response path while those store products are migrated. `career_profile_unlock` is explicitly rejected by that legacy path and must not derive user-wide subscription access. Remove the legacy resolver after the store-product migration is complete.
